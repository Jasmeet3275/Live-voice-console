## Redesigned the entire platform

### Changes in UX

1. The User Context Card has been converted into a collapsible, draggable sidebar on the left.
2. A summary of what is happening in the chat has been moved to the right collapsible, draggable sidebar, giving the operator a summarized view at all times.
3. In the mobile view, user details and booking information have been moved to the next page to provide a better UX.
4. All input checkpoints for the operator have been moved inline instead of being displayed in modals, ensuring greater consistency.
5. The Booking Info sidebar converts into a booking form for the operator when they take over the call.

### Changes in UI

1. The entire design language has been redesigned.
2. The UI now uses a warmer color palette.
3. Each component has been redesigned and optimized for both desktop and mobile views.
4. Demo bar has been kept outside to keep UI focused.
